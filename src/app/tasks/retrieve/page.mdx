# Retrieve a task {{ tag: 'GET', label: '/v1/tasks/:id' }}

<Row>
  <Col>

    This endpoint allows you to retrieve a task by providing the task id. Refer to [the task model](/tasks/model) to see which properties are included with task objects.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="GET" label="/v1/tasks/:id">

    ```bash {{ title: 'cURL' }}
    curl http://localhost:8000/v1/tasks/tsk_abc123 \
      -H "Authorization: Bearer {token}"
    ```

    ```python {{ title: 'Python' }}
    from agentflow import AgentFlowClient

    client = AgentFlowClient(token)

    task = client.tasks.get("tsk_abc123")
    ```

    </CodeGroup>
