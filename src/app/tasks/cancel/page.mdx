# Cancel a task {{ tag: 'POST', label: '/v1/tasks/:id/cancel' }}

<Row>
  <Col>

    This endpoint allows you to cancel a pending or running task. If the task is already completed or failed, the request will return an error.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="POST" label="/v1/tasks/:id/cancel">

    ```bash {{ title: 'cURL' }}
    curl -X POST http://localhost:8000/v1/tasks/tsk_abc123/cancel \
      -H "Authorization: Bearer {token}"
    ```

    ```python {{ title: 'Python' }}
    from agentflow import AgentFlowClient

    client = AgentFlowClient(token)

    client.tasks.cancel("tsk_abc123")
    ```

    </CodeGroup>
