# Retry a task {{ tag: 'POST', label: '/v1/tasks/:id/retry' }}

<Row>
  <Col>

    This endpoint allows you to retry a failed task. A new task is created with the same input and agent, and the retry counter is incremented.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="POST" label="/v1/tasks/:id/retry">

    ```bash {{ title: 'cURL' }}
    curl -X POST http://localhost:8000/v1/tasks/tsk_abc123/retry \
      -H "Authorization: Bearer {token}"
    ```

    ```python {{ title: 'Python' }}
    from agentflow import AgentFlowClient

    client = AgentFlowClient(token)

    retried = client.tasks.retry("tsk_abc123")
    ```

    </CodeGroup>
