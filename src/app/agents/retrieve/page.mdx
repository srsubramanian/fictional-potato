# Retrieve an agent {{ tag: 'GET', label: '/v1/agents/:id' }}

<Row>
  <Col>

    This endpoint allows you to retrieve an agent by providing the agent id. Refer to [the agent model](/agents/model) to see which properties are included with agent objects.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="GET" label="/v1/agents/:id">

    ```bash {{ title: 'cURL' }}
    curl http://localhost:8000/v1/agents/agt_abc123 \
      -H "Authorization: Bearer {token}"
    ```

    ```python {{ title: 'Python' }}
    from agentflow import AgentFlowClient

    client = AgentFlowClient(token)

    agent = client.agents.get("agt_abc123")
    ```

    </CodeGroup>

    ```json {{ title: 'Response' }}
    {
      "id": "agt_abc123",
      "name": "researcher",
      "instructions": "Research topics and summarize findings.",
      "model": "claude-sonnet-4-6",
      "tools": ["web_search", "fetch_data"],
      "memory": null,
      "max_retries": 3,
      "timeout": 300,
      "status": "active",
      "created_at": "2026-02-21T10:00:00Z",
      "updated_at": "2026-02-21T10:00:00Z"
    }
    ```
