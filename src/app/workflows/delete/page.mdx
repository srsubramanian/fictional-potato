# Delete a workflow {{ tag: 'DELETE', label: '/v1/workflows/:id' }}

<Row>
  <Col>

    This endpoint allows you to delete a workflow. Note: this will permanently delete the workflow definition. Any running workflow runs will be cancelled.

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="DELETE" label="/v1/workflows/:id">

    ```bash {{ title: 'cURL' }}
    curl -X DELETE http://localhost:8000/v1/workflows/wfl_abc123 \
      -H "Authorization: Bearer {token}"
    ```

    ```python {{ title: 'Python' }}
    from agentflow import AgentFlowClient

    client = AgentFlowClient(token)

    client.workflows.delete("wfl_abc123")
    ```

    </CodeGroup>

  </Col>
</Row>
