# List all workflows {{ tag: 'GET', label: '/v1/workflows' }}

<Row>
  <Col>

    This endpoint allows you to retrieve a paginated list of all your workflows. By default, a maximum of twenty workflows are shown per page.

    ### Optional attributes

    <Properties>
      <Property name="limit" type="integer">
        Limit the number of workflows returned. Defaults to `20`.
      </Property>
      <Property name="offset" type="integer">
        Number of workflows to skip for pagination.
      </Property>
      <Property name="status" type="string">
        Filter workflows by status: `"active"` or `"inactive"`.
      </Property>
    </Properties>

  </Col>
  <Col sticky>

    <CodeGroup title="Request" tag="GET" label="/v1/workflows">

    ```bash {{ title: 'cURL' }}
    curl -G http://localhost:8000/v1/workflows \
      -H "Authorization: Bearer {token}" \
      -d limit=10
    ```

    ```python {{ title: 'Python' }}
    from agentflow import AgentFlowClient

    client = AgentFlowClient(token)

    workflows = client.workflows.list(limit=10)
    ```
